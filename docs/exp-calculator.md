# คำนวณ EXP

<p class="lead">ใส่เลเวลกับ EXP ตอนนี้ และ EXP ที่ได้ต่อการส่งเควส (เช่นเควสหอ Tower of Chaos) ใส่ได้ 2 เควสถ้าทำพร้อมกัน และใส่จำนวนลูกแก้วที่มีเพื่อดูว่าส่งได้กี่ครั้ง แล้วดูว่าต้องส่งอีกกี่รอบถึงเลเวล 400</p>

<ul class="notes"><li>EXP ต่อเลเวลจาก <a href="https://wikimirror.lifeto.co/wiki.ggftw.com/trickster/Experience_Chart.html">Experience Chart ของวิกิ ggFTW</a> เป็นค่า EXP ที่ต้องเก็บในเลเวลนั้นเพื่อขึ้นเลเวลถัดไป</li><li>EXP ต่อรอบให้ดูจากหน้าต่างรางวัลเควสในเกม ถ้ามีบัฟ EXP ให้ใส่ค่าที่ได้จริงหลังบัฟ</li><li>ลูกแก้วคิดจากกองเดียวกัน ส่งเควสไหนก็ใช้ครั้งละ 50 ลูก (แก้ตัวเลขได้)</li><li>ตัวเลขที่ใส่จำไว้ในเบราว์เซอร์นี้</li></ul>
